# Takeldienst Faster — V2

Static, multi-page website designed as a professional local service site.

## Important
- Real Faster photos are intentionally not fabricated. Replace the photo slots with your own real images in `assets/images/`.
- Social links are placeholders until the actual profile URLs are supplied.
- The copy is a working draft and should be rewritten in the owner's own voice before final SEO publishing.
- Prices are intentionally not advertised. The site communicates “price vooraf” instead.
- The site includes Dutch, English, French and German entry pages.

## Deploy
This version is static HTML/CSS/JS and can be served directly by GitHub Pages. No build step is required.
